# 📝 Simple Memo App

React와 Vite를 사용해 만든 간단한 메모 애플리케이션입니다.  
Git 사용 연습과 Vercel 배포 연습을 목적으로 제작했습니다.

## 🔗 배포 주소
https://simple-memo-app-gold.vercel.app/

## ✨ 주요 기능
- 메모 추가
- 메모 삭제
- 전체 메모 삭제
- localStorage를 이용한 데이터 저장
- 새로고침 후에도 메모 유지

## 🛠 사용 기술
- React
- TypeScript
- Vite
- CSS
- localStorage
- Vercel (배포)
